# MOKI 白板 0.1.8 · r11 — 工具提示与自动切换 / Tool hints and automatic switching

应用版本保持 0.1.8，本次发布批次为 r11。 / App version remains 0.1.8; this is package revision r11.

## 本次更新

- 工具栏悬浮时在上方展示功能与快捷键提示，补充橡皮 E、箭头 A、思维导图 M、文件 F、链接 L 快捷键。
- 设置 → 常规 → 白板交互新增“自动切换工具”，默认开启。粘贴 / 置入图片、视频和文件，添加便签、链接、思维导图，完成图形、文字或钢笔路径后切回选择工具，方便移动和调整；自由画笔连续绘制保持当前工具。
- 开关记忆并同步到同一客户端的多个白板窗口；素材上传期间手动切换工具或修改开关时，保留较新的操作意图。
- 共享只读画布支持拖选文字片段，通过 Ctrl / ⌘ + C、底部操作栏或右键菜单复制；保留框选、平移、旋转 / 缩放下的选取与局域网 HTTP 复制回退。
- Windows x64 与 macOS Apple Silicon arm64 使用同一批固定源码构建。

## Changes

- Tooltips appear above toolbar buttons with shortcut hints. Added E (eraser), A (arrow), M (mind map), F (files) and L (link).
- General settings now includes Automatic tool switching, enabled by default. Pasting / inserting media or files, adding notes, links or mind maps, and completing shapes, text or pen paths returns to Select. Continuous freehand drawing keeps the Draw tool.
- The preference persists and synchronizes across local whiteboard windows. Manual tool or preference changes during an upload take precedence.
- Read-only shared boards support dragging to select text snippets and copying with Ctrl / ⌘ + C, the selection toolbar or context menu, including an HTTP clipboard fallback on LAN links.
- Windows x64 and macOS Apple Silicon arm64 packages are built from the same pinned source.

## 安装 / Installation

Windows 安装包尚未代码签名。macOS 仅支持 Apple Silicon arm64，使用 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证。请核对 SHA-256；macOS 首次打开说明见 README。

Windows packages are unsigned. macOS packages support Apple Silicon arm64 only and use ad-hoc signing, without Developer ID signing or notarization. Verify SHA-256 checksums and follow the first-launch steps in the README.
