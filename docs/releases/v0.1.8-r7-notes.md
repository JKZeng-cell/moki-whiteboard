## English

Application version remains **0.1.8**; package revision is **v0.1.8-r7**. Historical release assets are preserved.

- **Perpendicular node connections:** endpoint tangents follow the normals of the actual node edges. Horizontal layouts enter from the side, downward layouts from above. Connections remain attached when nodes are offset, rotated, moved, or scaled.
- **Consistent preview and selection:** connection previews snap to node ports; cancelling preserves the relationship. Hit-testing follows the visible curve instead of the invisible straight chord.
- **Matching PNG exports:** use the same routing as the live canvas and include the full curved path in the export bounds. Existing snapshots with stale edge coordinates are supported without rebuilding their connections.

This revision retains r6 mind-map input resizing and canvas-export fixes, along with multi-window editing and LAN sharing.

Windows x64 and macOS Apple Silicon arm64 only. Windows is unsigned; macOS is ad-hoc signed without Developer ID signing or Apple notarization. Verify provenance and SHA-256 before using Open / Open Anyway or the scoped quarantine command above. Do not disable Gatekeeper globally.
