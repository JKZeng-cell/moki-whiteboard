# MOKI Whiteboard 0.1.8 · 2026-11-05 共享功能更新 / Sharing update

应用版本保持 **0.1.8**，本次安装包发布批次为 **v0.1.8-r3**，保留全部历史下载。

- 开启局域网共享后，编辑页右上角新增快速共享按钮，可生成、复用和复制当前白板链接。
- 白板管理卡片的导出、重命名、复制、共享和删除操作统一收纳到“更多”菜单。
- 共享页沿用主程序的分组页面菜单及素材列表，支持搜索、定位、预览、切页和分组展开 / 收起。
- 共享画布可直接播放视频；素材预览支持图片、视频、音频、PDF 和文本，其他附件可下载。
- 保留共享页的缩放、重置、全屏、PNG 导出、快捷键提示和深浅色模式。
- 分享始终只读：访客不能修改内容；附件按分享链接和白板范围读取，不暴露本机文件路径；关闭或停止共享会使旧链接失效。
- 本批次包含上一批次的页面视图记忆、原文件编辑保存、不设 MB / GB 业务大小上限的互导和视频直角显示更新。

分享需要保持应用运行，访问设备须处于同一局域网。附件播放能力取决于浏览器支持的媒体格式；不提供 Office 在线编辑和文件夹浏览。

**下载平台：** Windows x64（安装 EXE / 免安装 ZIP）和 macOS Apple Silicon arm64（DMG / 应用 ZIP）。Intel Mac 暂不支持。

Windows 安装包未签名；macOS 为 ad-hoc 签名，没有 Developer ID 或 Apple 公证。macOS 如提示无法验证开发者，请先确认下载来源并核对 SHA-256，再右键应用 → 打开，或在“系统设置 → 隐私与安全性”中允许打开。若已确认文件可信而下载隔离属性仍阻止运行，仅针对已安装应用执行：

```sh
xattr -dr com.apple.quarantine "/Applications/MOKI 白板.app"
```

无需关闭系统 Gatekeeper。发布前执行双平台原生构建、客户端 / MCP / 原文件保存验收、源码一致性和归档完整性检查；不等同于干净机器安装、真实重启登录或覆盖升级测试。

## English

This release keeps application version **0.1.8**, publishes a new **v0.1.8-r3** package revision, and preserves all previous downloads.

- Quickly generate, reuse, and copy the current board's LAN share link from the editor header when sharing is enabled.
- Access export, rename, duplicate, share, and delete actions from one board-card **More** menu.
- Shared boards use the main application's grouped page menu and materials panel, including search, locate, preview, page switching, and group expansion.
- Play videos directly on the shared canvas; preview images, video, audio, PDF, and text, or download other attachments.
- Retain zoom, reset view, fullscreen, PNG export, shortcut help, and light / dark appearance.
- Sharing remains read-only. Guests cannot edit content, attachments are scoped to the shared board, local filesystem paths are hidden, and stopping sharing invalidates old links.
- Includes the previous refresh's per-page view memory, original-file editing and saving, portable transfers without preset MB / GB business limits, and square video corners.

Keep the application running and use the same LAN. Playback depends on browser codec support. Office online editing and folder browsing are unavailable.

Windows x64 and macOS Apple Silicon arm64 only. Windows is unsigned; macOS is ad-hoc signed, without Developer ID signing or Apple notarization. Verify the source and SHA-256 before using right-click **Open** or **Open Anyway**. If quarantine still blocks a trusted installation, the scoped `xattr` command above applies only to that application. Do not disable Gatekeeper globally. Native build, app / MCP / original-file smoke checks, compiled-source matching, and archive integrity checks do not replace clean-machine installation, real reboot / login, or in-place upgrade testing.
