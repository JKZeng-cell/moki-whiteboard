# MOKI Whiteboard 0.1.8 · r10 · 深色列表与菜单 / Dark lists and menus

- 优化管理页、编辑器和共享页的列表与菜单配色，覆盖页面分组、资料库多级目录、素材和版本记录。
- 统一弹窗、搜索框和子菜单的深色背景，并区分选中、悬停、键盘焦点和删除操作。
- Windows x64 提供 EXE 与免安装 ZIP。macOS Apple Silicon 提供 DMG 与应用 ZIP。首次启动说明和校验文件见 README 与本页附件。

- Updated dark styling for lists and menus across the board manager, editor and shared viewer, including page groups, nested resource folders, attachments and version history.
- Dialogs, search fields and submenus use a consistent dark palette with distinct selection, hover, keyboard focus and delete states.
- Windows x64 ships as an EXE and portable ZIP. Apple Silicon Macs can use the DMG or app ZIP. See the README and release assets for first-launch instructions and checksums.
