# MOKI Whiteboard 0.1.8 · 2026-11-10 共享下载与视频拖动 / Shared downloads and video dragging

应用版本保持 **0.1.8**，发布批次为 **v0.1.8-r8**，保留历史下载。

- **视频置入即可拖动**：不必等元数据或首帧加载，画面拖动与原生播放控件分开，保留播放、进度条和撤销重做。
- **页面列表持续展开**：切换页面后保留列表和搜索条件，可连续选页，由用户手动收起；编辑页及共享只读页一致。
- **共享页下载原始素材**：选中操作栏与右键菜单提供下载，支持图片、视频、音频和文件，多选或收起的编组支持批量下载；共享原始附件交由浏览器下载，保持只读访问。

- **GitHub 更新提示**：启动后自动检查正式发布，支持相同应用版本下的 r8 / r9 批次比较。用户点击后才下载，按大小和 SHA-256 校验，完成后打开安装包目录手动安装，不中断白板编辑。首次需安装本次 r8，之后发布的更新可自动提示。

保留 r7 的思维导图连线、r6 输入宽度 / 截图修复，以及多窗口、原文件写回和局域网共享功能。

Windows x64（安装 EXE / 免安装 ZIP）与 macOS Apple Silicon arm64（DMG / 应用 ZIP）。暂不提供 Intel Mac 构建。

Windows 未签名；macOS 为 ad-hoc 签名，没有 Developer ID 或 Apple 公证。先确认下载来源并核对 SHA-256。macOS 首次打开可右键应用 → 打开，或在“系统设置 → 隐私与安全性”允许打开。如仍被下载隔离属性阻止，确认来源可信后仅针对本应用执行：

```sh
xattr -dr com.apple.quarantine "/Applications/MOKI 白板.app"
```

无需关闭 Gatekeeper。原生构建、成品验证及归档完整性检查不替代干净机器安装、真实重启登录或覆盖升级验收。

## English

Application version remains **0.1.8**; package revision is **v0.1.8-r8**. Historical release assets are preserved.

- **Drag videos immediately after insertion:** move the picture while metadata or the first frame is still loading. Playback controls, seeking, and undo/redo remain available.
- **Keep the page list open:** switching pages retains the list and search query until the user dismisses it, in both the editor and read-only shared viewer.
- **Download original shared materials:** the selection toolbar and context menu support images, video, audio, and files, including multiple selections and collapsed groups. Shared attachments use the browser downloader while preserving read-only access.

- **GitHub update prompts:** check stable releases automatically and compare revision tags even when the app version is unchanged. Download only after a click, verify size and SHA-256, then reveal the installer for manual installation without interrupting editing. Install r8 once to receive prompts for future releases.

Retains r7 mind-map routing, r6 input resizing and canvas-export fixes, multi-window editing, original-file save-back, and LAN sharing.

Windows x64 and macOS Apple Silicon arm64 only. Windows is unsigned; macOS is ad-hoc signed without Developer ID signing or Apple notarization. Verify provenance and SHA-256 before using Open / Open Anyway or the scoped quarantine command above. Do not disable Gatekeeper globally. Native builds and packaged/archive checks do not replace clean-machine installation, reboot/login, or in-place upgrade testing.
