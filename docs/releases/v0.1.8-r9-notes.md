Application version remains **0.1.8**, with package revision **v0.1.8-r9**.

- LAN sharing tabs now show **Board name - MOKI 白板**, making multiple shared boards easier to identify.
- Tab titles follow board renames on refresh and return to the product title when sharing becomes unavailable.
- Retains r8 video dragging, persistent page lists, shared attachment downloads and GitHub update notifications.

Windows x64 installers / portable ZIPs and macOS Apple Silicon arm64 DMG / app ZIPs are provided. Windows packages are unsigned; macOS packages are ad-hoc signed, without Developer ID signing or notarization. See the bilingual README for first-launch instructions. Previous releases are preserved.
