# MOKI Whiteboard 0.1.8 · 2026-11-05 多窗口与共享体验更新 / Multi-window and sharing update

应用版本保持 **0.1.8**，安装包发布批次为 **v0.1.8-r5**，保留所有历史下载。

- **客户端多窗口**：白板卡片“更多 → 在新窗口打开”，编辑页也可将当前白板移到新窗口，原窗口返回管理页。不同白板可同时独立编辑与保存；同一白板已打开时直接切换其窗口。
- **窗口独立操作**：文件选择、另存为、右键菜单、截图和 Agent 选区按窗口隔离；批量打开文件时保留正在编辑的白板。托盘列出已打开的窗口，可恢复隐藏白板。
- **退出保存保护**：退出前保存所有窗口，包括隐藏窗口和绑定的原文件；保存失败保留窗口与草稿。修复后台窗口缩略图绘制可能拖住退出的问题。
- **共享页交互**：支持选中、框选、多选、复制及只读右键菜单。访客可收起 / 展开编组，仅影响自己的视窗，分页和分享者内容更新后仍保留状态。
- **跨应用复制**：文字以可读文本复制，图片及完整编组可粘贴回 MOKI；支持局域网 HTTP 下的复制和 PNG 富文本。视频与文件复制为附件链接。中间应用移除白板元数据后，图片 HTML 仍可粘贴为图片。
- **共享访问统计**：共享画布、分享弹窗和设置卡片显示在线人数；同浏览器多标签页合并计数，异常断线最多 75 秒校正。
- **历史访问**：设置中可查看单张白板或全部访问记录，包括浏览器 / 设备、局域网地址、访问时间和停留时长，支持分页。记录仅保存在本机，分享者可见；取消共享或关闭服务后仍保留。记录从更新后开始，不追溯此前未记录的访问。
- **布局优化**：共享卡片的链接和操作分行排列，统一复制 / 历史访问 / 取消共享的布局，适配深浅色与小窗口。

共享内容仍只读；访客操作不修改原白板。分享者需保持应用运行，访问设备须处于同一局域网。附件播放取决于浏览器格式支持；视频 / 文件的复制链接在停止共享后会失效。

**下载平台：** Windows x64（安装 EXE / 免安装 ZIP）与 macOS Apple Silicon arm64（DMG / 应用 ZIP）。Intel Mac 暂不支持。

Windows 安装包未签名；macOS 为 ad-hoc 签名，没有 Developer ID 或 Apple 公证。请先确认下载来源并核对 SHA-256；macOS 可右键应用 → 打开，或在“系统设置 → 隐私与安全性”允许打开。如已确认安装可信而下载隔离属性仍阻止启动，仅针对已安装应用执行：

```sh
xattr -dr com.apple.quarantine "/Applications/MOKI 白板.app"
```

无需关闭 Gatekeeper。原生构建、成品客户端 / MCP / 多窗口文件打开、源码一致性和归档完整性验证不等同于干净机器安装、真实重启登录或覆盖升级验收。

## English

Application version remains **0.1.8**. This update publishes package revision **v0.1.8-r5** while preserving previous downloads.

- **Multiple desktop windows:** open a board from its card's More menu, or move the current editor into a new window and return the source window to the manager. Edit different boards independently; reopening an existing board focuses its window.
- **Window isolation:** native file/save dialogs, context menus, captures, and Agent selections belong to their requesting window. Opening multiple files preserves existing editors. Restore hidden board windows from the tray.
- **Safe quitting:** save all open and hidden windows and their bound original files before exit. Save failures preserve windows and drafts. Thumbnail rendering in background windows can no longer hold up quitting indefinitely.
- **Shared-view interaction:** select, marquee, multi-select, copy, and use a read-only context menu. Collapse or expand groups only in your own viewport; retain that state across page changes and owner updates.
- **Cross-app clipboard:** readable text, images, and complete groups can be copied, including on non-secure LAN HTTP. PNG rich-text copy is available. Video and file content copy as attachment links. Raster image HTML still pastes as an image if an intermediate app strips MOKI metadata.
- **Visitor statistics:** show online counts on the shared canvas, share dialog, and settings cards. Deduplicate tabs by browser; abandoned sessions expire within 75 seconds.
- **Visit history:** view paginated per-board and global history with browser/device, LAN address, timestamps, and duration. Records stay on the host, are owner-only, and remain after revocation or disabling sharing. Recording starts with this update; previous unrecorded visits cannot be recovered.
- **Refined layout:** separate shared-card link and action rows, with consistent copy/history/revoke controls in light, dark, and narrow windows.

Shared content remains read-only. Keep the host app running and use the same LAN. Playback depends on supported media formats. Copied video/file links stop working when sharing is revoked.

Windows x64 and macOS Apple Silicon arm64 only. Windows is unsigned; macOS is ad-hoc signed without Developer ID signing or Apple notarization. Verify the source and SHA-256 before using **Open** / **Open Anyway** or the scoped quarantine command above. Do not disable Gatekeeper globally. Native builds, packaged app / MCP / multi-window file-open checks, source parity, and archive integrity do not replace clean-machine installation, reboot/login, or in-place upgrade testing.
