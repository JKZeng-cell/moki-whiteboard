# MOKI Whiteboard 0.1.8 · 2026-11-05 设置与缩放修复 / Settings and zoom fixes

应用版本保持 **0.1.8**，本次安装包发布批次为 **v0.1.8-r4**，保留全部历史下载。

- 修复设置弹窗滚动条：固定标题与分类，内容独立滚动，细滚动条适配深浅色和圆角。
- 局域网设置改为已共享白板列表，可复制链接和逐项取消共享；生成链接继续使用编辑页或白板卡片的共享入口。
- 局域网共享默认开启，保留手动关闭偏好；只开启服务，不会自动共享全部白板。
- 共享链接卡片可单击打开网页，拖动不误触、双击不重复开页，并拒绝非法协议。
- 共享页 Ctrl/⌘ + 滚轮只缩放画布，避免与浏览器页面缩放冲突；支持画布、视频、素材列表与顶部区域。
- 深色模式下的画布边缘改为低对比度描边，编辑页和共享页保持一致。
- 保留上一批次的快速共享、只读分页和素材列表、音视频 / 图片 / 文本 / PDF 预览、附件下载、原文件编辑保存和无预设 MB / GB 业务大小上限的互导。

分享需要保持应用运行，访问设备须处于同一局域网。附件播放能力取决于浏览器支持的媒体格式；不提供 Office 在线编辑和文件夹浏览。

**下载平台：** Windows x64（安装 EXE / 免安装 ZIP）和 macOS Apple Silicon arm64（DMG / 应用 ZIP）。Intel Mac 暂不支持。

Windows 安装包未签名；macOS 为 ad-hoc 签名，没有 Developer ID 或 Apple 公证。macOS 如提示无法验证开发者，请先确认下载来源并核对 SHA-256，再右键应用 → 打开，或在“系统设置 → 隐私与安全性”中允许打开。若已确认文件可信而下载隔离属性仍阻止运行，仅针对已安装应用执行：

```sh
xattr -dr com.apple.quarantine "/Applications/MOKI 白板.app"
```

无需关闭系统 Gatekeeper。发布前执行双平台原生构建、客户端 / MCP / 原文件保存验收、源码一致性和归档完整性检查；不等同于干净机器安装、真实重启登录或覆盖升级测试。

## English

This release keeps application version **0.1.8**, publishes a new **v0.1.8-r4** package revision, and preserves all previous downloads.

- Fix settings scrolling with a fixed heading / tabs, an independent content area, and slim scrollbars that match light / dark appearance and rounded corners.
- Manage existing shared boards under Settings: copy links and revoke individual shares. Create links from the editor header or a board card’s More menu.
- Enable the LAN service by default while retaining explicit off preferences. Boards are shared only when a user generates a link.
- Open shared link cards with one click; dragging does not open links, double-clicking opens once, and unsafe protocols are rejected.
- Route Ctrl/⌘ + wheel to canvas zoom without changing browser page zoom, including gestures over media, materials, and the header.
- Use subtle, consistent canvas borders in dark appearance for editing and shared views.
- Retain quick sharing, read-only grouped pages / materials, multimedia / text / PDF previews, downloads, original-file editing, and portable transfers without preset MB / GB business limits.

Keep the application running and use the same LAN. Playback depends on browser codec support. Office online editing and folder browsing are unavailable.

Windows x64 and macOS Apple Silicon arm64 only. Windows is unsigned; macOS is ad-hoc signed, without Developer ID signing or Apple notarization. Verify the source and SHA-256 before using right-click **Open** or **Open Anyway**. If quarantine still blocks a trusted installation, the scoped `xattr` command above applies only to that application. Do not disable Gatekeeper globally. Native build, app / MCP / original-file smoke checks, compiled-source matching, and archive integrity checks do not replace clean-machine installation, real reboot / login, or in-place upgrade testing.
