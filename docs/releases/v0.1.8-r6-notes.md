# MOKI Whiteboard 0.1.8 · 2026-11-06 思维导图与截图修复 / Mind-map editing and canvas export fixes

应用版本保持 **0.1.8**，安装包发布批次 **v0.1.8-r6**。历史下载保持不变。

- **思维导图输入宽度**：双击节点后拖动输入框右侧拖柄，调整宽度且不拉伸字号。支持方向键微调、自动换行和高度增长，完整保留长文本；提交后保存宽度，支持撤销 / 重做，Esc 取消。
- **编辑体验**：缩放后的拖动按画布和节点比例正确换算；连线跟随节点边缘。修复窄输入框尾行裁切及文字工具栏重复位移问题。
- **Agent 编辑后截图**：修复外链图片导致自动缩略图、PNG 导出或 Agent 选区截图报 `Tainted canvases may not be exported`。图片按 CORS 加载，并在绘入画布前验证可读取。
- **保留完整内容**：若图片源禁止跨域读取或暂不可用，保留上次缩略图，不导出缺图 PNG；手动导出会提示先下载图片并作为本地素材重新置入。失败截图延后重试，新编辑版本立即重新尝试。清空页面使用全新空白缩略图。

Windows x64（安装 EXE / 免安装 ZIP）与 macOS Apple Silicon arm64（DMG / 应用 ZIP）。暂不提供 Intel Mac 构建。

Windows 未签名；macOS 使用 ad-hoc 签名，没有 Developer ID 或 Apple 公证。先确认下载来源并核对 SHA-256。macOS 首次打开可右键应用 → 打开，或在“系统设置 → 隐私与安全性”允许打开；若仍受下载隔离属性阻止，确认安装来源可信后仅针对本应用执行：

```sh
xattr -dr com.apple.quarantine "/Applications/MOKI 白板.app"
```

无需关闭 Gatekeeper。原生构建、成品验证与归档校验不替代干净机器安装、真实重启登录或覆盖升级验收。

## English

Application version remains **0.1.8**; package revision is **v0.1.8-r6**. Earlier release assets are preserved.

- **Mind-map input width:** double-click a node and drag its right-side handle without scaling the font. Arrow keys provide fine adjustment. Text wraps and the node grows vertically as needed; saved widths support undo/redo and reopening. Escape cancels the draft.
- **Editing improvements:** account for canvas/node scale, update connected edges, avoid clipped last lines, and keep the formatting toolbar correctly positioned.
- **Agent-triggered screenshots:** fix cross-origin images tainting the canvas during automatic thumbnails, PNG export, and Agent visual-selection capture. Request images with CORS permission and verify pixel readability before drawing.
- **Complete exports:** retain the previous thumbnail when an image cannot be read, and reject incomplete PNG exports with a clear message. If a source disallows CORS, download and insert the image locally. Retry failed thumbnails later or immediately for a new document version. Empty pages receive a fresh blank thumbnail.

Windows x64 and macOS Apple Silicon arm64 only. Windows is unsigned; macOS is ad-hoc signed without Developer ID or Apple notarization. Verify download provenance and SHA-256 before using Open / Open Anyway or the scoped quarantine command above. Do not disable Gatekeeper globally. Native builds, packaged checks, and archive integrity do not replace clean-machine installation, reboot/login, or in-place upgrade testing.
