## MOKI 白板 0.1.8

- 关闭窗口后可继续在系统托盘运行，MCP 服务保持可用；托盘菜单可重新打开白板或退出应用。
- 桌面设置支持开机自启动，默认关闭，由用户主动启用。
- MCP 设置支持复制一整段接入说明给 Agent，包含当前 stdio / Streamable HTTP 配置和使用步骤。
- 更新应用图标：以手指轮廓表达 M 和击掌协作的寓意，掌心保持留白。
- 整理桌面生命周期相关代码，退出前保存正在编辑的内容。

下载 Windows x64 安装程序（EXE）或便携包（ZIP）；Apple Silicon Mac 下载 DMG 或 ZIP。Intel Mac 暂不支持。

## MOKI Whiteboard 0.1.8

- Keep the app and its local MCP service running in the system tray after closing the window; reopen or quit from the tray menu.
- Opt in to launch at login from desktop settings (off by default).
- Copy a complete Agent onboarding prompt with the current stdio / Streamable HTTP configuration and connection steps.
- New application icon: an open palm with M-shaped finger contours, expressing collaboration.
- Clean up desktop lifecycle code and flush active edits before quitting.

Windows x64: EXE installer or portable ZIP. Apple Silicon macOS: DMG or ZIP. Intel Mac is currently unsupported.

### Verification / 验证

Both platforms were built from source commit `7627f2245948c4ec170a9d1e008f296a131046a2`. The release tag points to this application source; subsequent documentation and publication-workflow commits do not change the installer bytes.

源代码检查及 277 项测试通过。Windows 和原生 macOS 安装包均通过独立数据目录下的启动、16 项 MCP 工具、文件打开、Office 预览、设置及托盘生命周期检查；ZIP/DMG 完整性检查通过。尚未验证真实重启后的自启动、全新电脑安装或已有安装的升级。

Source checks and all 277 tests passed. Packaged Windows and native macOS checks covered launch with isolated data, 16 MCP tools, file opening, Office previews, settings, and tray lifecycle. Archive integrity checks passed. Real reboot/login startup, clean-machine installation, and upgrading an installed copy have not been verified.

Windows binaries are unsigned. macOS binaries are ad-hoc signed, without a Developer ID signature or Apple notarization. Verify the download against `SHA256SUMS-0.1.8.txt`; see the [macOS first-launch instructions](https://github.com/JKZeng-cell/moki-whiteboard#macos-first-launch-en) if macOS blocks first launch. Do not disable Gatekeeper or SIP globally.

Windows 程序尚未数字签名；macOS 使用临时签名，未通过开发者认证或 Apple 公证。请先核对 SHA256，再按 [macOS 首次启动说明](https://github.com/JKZeng-cell/moki-whiteboard#macos-first-launch)操作。
