# MOKI 白板 0.1.8 · 2026-11-04 更新

应用版本保持 0.1.8，本批次为新的 `v0.1.8-r2` 下载，保留原有 Release。

- 新增局域网只读共享：按白板生成链接，支持复制、撤销和统一关闭。
- 每个页面记住缩放与位置，重新进入恢复上次视图；缩放区新增重置按钮。
- 导入、导出、直接打开和附件恢复不再设置 MB / GB 业务大小上限；实际容量受设备资源和运行环境影响。
- 大媒体使用素材目录存储，浏览器附件改为二进制传输。
- 导出文件可重新打开、编辑并写回原文件，保留分页和附件；保存时继续检查外部修改冲突。
- 视频预览、播放和占位卡片取消圆角裁切。

Windows x64：下载 `Setup` EXE 安装，或使用 Windows ZIP。macOS：仅 Apple Silicon arm64，下载 DMG 或完整应用 ZIP。

Windows 未签名；macOS 为 ad-hoc 签名，没有 Developer ID 或 Apple 公证。如 macOS 提示无法验证开发者，先确认来源并核对 SHA-256，再尝试右键应用 → 打开，或在“系统设置 → 隐私与安全性”中允许打开。若确认文件可信但下载隔离属性仍阻止运行，可仅针对已安装的应用执行：

```sh
xattr -dr com.apple.quarantine "/Applications/MOKI 白板.app"
```

不需要关闭系统 Gatekeeper。Intel Mac 暂不支持。当前验证不等同于真实重启登录、干净机器安装或覆盖升级测试。

This refresh keeps application version **0.1.8** and publishes a separate **v0.1.8-r2** release, preserving earlier downloads.

- Read-only LAN sharing with per-board links, copy, revocation, and a master switch.
- Per-page zoom / pan memory and a reset-view control.
- No preset MB / GB business limits on portable import / export, direct opening, or attachment restoration; practical capacity depends on hardware and runtime resources.

- Reopen exported boards, edit, and save to the original file with pages, attachments, and external-change protection intact.
- Square video preview, playback, and placeholder corners.

Windows x64 and macOS Apple Silicon arm64 only. Windows is unsigned; macOS is ad-hoc signed and is not Developer ID-signed or notarized. Verify the download and checksums before using macOS Open Anyway / right-click Open. If quarantine still blocks the trusted app, the scoped `xattr` command above targets only that application. Do not disable Gatekeeper globally. Real reboot/login, clean-machine installation, and in-place upgrades are not covered by the current smoke checks.
