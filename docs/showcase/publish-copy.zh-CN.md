标题：MOKI白板开源啦🎉让AI加入创作

做方案、整理灵感时，总要在图片文件夹、网页收藏、文档和视频之间来回切换。

所以，我把 MOKI 的无限白板拆成了独立应用，并把它开源了 ✨

🖥️ 不止是画布 是你的自由桌面
图片、视频、网页、文档、应用程序文件，都能放到同一张画布里。把参考、素材和待办摆在一起，让想法自由生长。

✍️ 灵感来了，直接画下来
用画笔写写画画，加上箭头、图形和便签。文字、涂鸦和素材可以在同一个创作现场碰撞。

🧠 让 AI 加速你的思考落地
思维导图支持 Agent 调用。从一句目标开始，协助拆解方向、生成节点，再由你继续补充、调整和细化。

📑 复杂项目 也能清晰翻页
灵感收集、用户研究、视觉方案、发布清单……用分页和分组组织不同阶段，随时切换，不丢上下文。

🗂️ 再多内容 也能随取随用
通过素材列表快速搜索、定位、预览和打开。图片看缩略图，文件看类型，找素材少一点翻找，多一点直觉。

📁 编组收起为虚拟文件夹 分组管理整洁有序
把相关图片、文件和便签编为一组，收起成画布里的虚拟文件夹。暂时不用就收起来，需要时再展开，让素材各归其位，画布清爽，创作更有条理。

🔎 让 Agent 找素材，带回画布整理
告诉它你想找什么、喜欢什么风格。让 Agent 协助搜集参考，再通过 MCP 置入画布，按主题分类、整齐排布，方便你对比和继续创作。

🤖 通过 MCP，让 Agent 协助你的创意
素材收集、内容整理、思维导图、图片创作——把 Agent 的产出带回画布，让对话里的想法真正落到创作现场。

💾 本地优先，素材与白板保存在自己的电脑。
🌗 支持浅色、深色与跟随系统。
